2

Schedule & publish a class

sequenceDiagram
    participant T as Teacher
    participant A as Admin
    participant S as Student

    Note over T: Teacher saves class draft (details + lessons)
    Note over A: Admin proposes schedule on class schedule page
    A->>T: Schedule pending instructor approval

    alt Teacher approves
        T->>A: Schedule approved
        Note over A: Admin publishes class
        A->>S: Student Available Classes
    else Teacher requests changes
        T->>A: Rejection note
        Note over A: Admin revises and re-proposes
    end

Enroll and pay

Join a class

sequenceDiagram
    participant S as Student
    participant A as Admin

    Note over S: Student Available Classes
    Note over S: Open class then Join Class
    S->>A: Submit enrollment form
    Note over S: Waiting on Dashboard or Available Classes

    alt Approved
        A->>S: Enrolled - Student My Class
    else Rejected
        A->>S: Rejected
        Note over S: Apply again from Available Classes
    end

Substitute teacher cover

sequenceDiagram
    participant T1 as Primary Teacher
    participant A as Admin
    participant T2 as Substitute

    Note over T1: Teacher requests cover from My Class
    T1->>A: Submit substitute request
    Note over A: Admin Operations Substitute cover requests
    A->>T2: Send substitute invite
    alt Accepts
        Note over T2: Teacher Attendance QR or My Class session
        T2->>A: Session covered
    else Declines
        T2->>A: Decline
        Note over A: Admin Substitute cover requests find another
    end
